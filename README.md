# Clarity Planner Extension

A Chrome extension for planning, tracking, and managing tasks with a focus on clarity and vision.

## Features

- **Dashboard** - Overview of your projects and tasks
- **Planner** - Plan and organize your work
- **Tracker** - Track your progress and time
- **Vision** - Keep sight of your goals and vision
- **Capture** - Quickly capture ideas and tasks

## Project Structure

```
├── manifest.json          - Extension configuration
├── background/            - Service worker
├── pages/                 - Main extension pages (dashboard, planner, tracker, vision)
├── popup/                 - Popup UI
├── capture/              - Capture functionality
├── shared/               - Shared utilities and styles
└── assets/               - Icons and resources
```

## Installation

1. Clone this repository
2. Open Chrome and navigate to `chrome://extensions/`
3. Enable "Developer mode"
4. Click "Load unpacked" and select this project folder

## Development

No build process required - edit files directly and reload the extension in Chrome.
